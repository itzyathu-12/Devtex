# Devtex

Devtex is a developer workspace tool that provides a CLI and a desktop application for managing projects and interacting with AI providers.

## Features

- **CLI**: Initialize and manage Devtex projects from the terminal.
- **Desktop**: Electron‑based GUI for a richer experience.
- **AI Providers**: Integration with Gemini, Groq, OpenAI‑compatible APIs.

## Getting Started

### Prerequisites

- Node.js 20+ (or newer)
- npm or yarn

### Installation

```bash
npm install -g devtex-cli
```

### Usage

```bash
# Initialize a new Devtex project
devtex init

# Run the desktop application
npx devtex-desktop
```

## Project Structure

- `Devtex-CLI/`: CLI source code.
- `Devtex-Desktop/`: Electron desktop application.
